# Filosofía & Política
Proyecto personal de aprendizaje de Rodrigo Vidal.

Portal: https://rozoca.github.io/filosofia-politica/

18 módulos históricos y un epílogo, exploración temática y Laboratorio de pensamiento con preguntas, casos, dilemas y ejercicios de transferencia. Sitio estático compatible con GitHub Pages.

- [Guía de mantenimiento y actualización](MAINTENANCE.md)
- [Auditoría inicial](AUDIT.md)
- [Validación y límites de la entrega](VALIDATION.md)

Construir componentes: `python scripts/build.py`.
Validar: `python scripts/validate.py`.
Previsualizar: `python -m http.server 8000` y abrir http://localhost:8000.

La evolución de octubre de 2026 está publicada. Consulta VALIDATION.md para conocer las comprobaciones y limitaciones.
